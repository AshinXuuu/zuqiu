# 足球预测下注工具 · 升级说明与诚实结论

> 核心思想:**预测并赚钱**。
> 但「赚钱」唯一可信的证据不是漂亮的命中率,而是 **对收盘线持续正的 CLV + 足够大的样本**。
> 这次升级把工具从「重算市场的数」改成「能检验自己到底有没有 edge」。

---

## 这次新增/改了什么

| 文件 | 作用 |
|---|---|
| `download_data.py` | **在你本机运行**(沙盒不能联网)。批量拉 football-data.co.uk 多联赛多赛季,含开盘+收盘 Pinnacle 的 1X2/大小球/亚盘,清洗成 `data/matches_clean.csv`。可扩到数千场。 |
| `model_dc.py` | **独立模型**:Dixon-Coles 双泊松 + 时间衰减,只用历史进球估球队攻防强度,**不看赔率**。只有独立于市场的概率,才有资格谈"比市场准"。 |
| `backtest_value.py` | **价值下注回测引擎**:walk-forward(只用开赛前数据)→ 模型概率 vs 市场 → 价值阈值下注 → 算 ROI、命中率、**平均 CLV、CLV 的 t 统计、ROI 的 bootstrap 区间**,分盘口拆解。 |
| `data/epl_2425_sample.csv` | 把原 68 场真实数据抽成干净 CSV,供即时演示。 |
| `predict.py` | **参考预测工具(向市场收缩)**:模型概率与市场公允概率按 α 混合,输出对照+分歧标记。定位=二次意见,不是 edge。 |
| `clv_tracker.py` | **个人逐注 CLV 记分卡**:记进场/收盘赔率与结果,算滚动 CLV、t 统计、ROI,判读你到底有没有在加价值。 |
| `score_from_market.py` | **用 Pinnacle 多盘口反推公允比分分布**(1X2+大小球+让球同时拟合),输出公允比分赔率;贴入软盘比分价自动找 value。这是"能拿到的最好比分概率",用来量**软盘**错价。 |

旧文件(`decode_odds.py` / `backtest_real.py`)保留,作为"赔率解码"演示;
新引擎才是判断赚不赚的工具。

## 现在能给的真实结论(68 场样本)

跑 `backtest_value.py`(模式 B,以收盘为真值找开盘价值):

```
[全部]  注数 72 | 命中 25.0% | ROI -26.0% (95%CI -57~+8%) | 平均CLV +10.3% (t=+17.2)
[1X2]   注数 48 | 命中 18.8% | ROI -34.4%               | 平均CLV +11.5% (t=+13.8)
[大小球] 注数 24 | 命中 37.5% | ROI  -9.3%               | 平均CLV  +8.0% (t=+19.4)
```

**这组数字本身就是最重要的一课:**

1. **CLV 极强为正(t=17),ROI 却是 −26%。** 这正是你检查清单第 2 节说的——
   过程对(持续买到比收盘更长的价)≠ 短期一定赢。**72 注什么都证明不了**,
   方差完全压过信号(ROI 的 95% 区间从 −57% 到 +8%,跨 0)。
2. 别再盯命中率。25% 命中配深红 ROI,但 CLV 告诉你方向没错。
3. **模式 B 是按构造得正 CLV 的**(专挑开盘比收盘长的注),所以它只证明
   "流程跑通 + 跟线步进",**不能证明你有独立 edge**。真 edge 必须用模式 A。

## ★ 模式 A 真实结论(10,707 场 · 5 大联赛 · 6 赛季)

`download_data.py` 拉到 1 万+ 场后跑 `backtest_value.py`(自动切模式 A,
walk-forward 独立 Dixon-Coles 模型 vs 开盘 Pinnacle):

```
样本 10707 场 | 预测 9779 场 | 价值阈值 3%
[全部]  注数 17855 | 命中 37.6% | ROI -4.80% (95%CI -6.9~-2.5%) | 平均CLV -0.44% (t=-6.94)
[1X2]   注数 10839 | 命中 29.4% | ROI -6.06%                    | 平均CLV -0.50% (t=-5.46)
[大小球] 注数  7016 | 命中 50.2% | ROI -2.85%                    | 平均CLV -0.34% (t=-4.46)
```

**结论(确凿,不是噪声了):这个基础 Dixon-Coles 模型对 Pinnacle 没有 edge。**

- 1.8 万注、t=-6.9 的**负 CLV** —— 不是样本不够,是模型**系统性地比市场更笨**。
  收盘是终极裁判,它判了:模型的"价值信号"其实是自己的误差。
- ROI -4.8% 的 95% 区间整段在 0 以下,也确凿为负。别下注。
- 这正是检查清单预言的结局,也是**最有用的结果**:工具诚实地告诉你"你没 edge"。
- 唯一相对"最不差"的是**大小球**(-0.34% CLV)—— 和它水位最低、模型在这相对没那么错一致。

> 注:为在演示环境里快速跑完用了较稀疏重训(每150场)。你本机可用更密的
> `refit_every=20` 复跑,结论不会反转(负 CLV 差太多,不可能翻正)。

**这意味着:别再 tune 这个模型了——它结构上就落后 Pinnacle。** 想要真 edge,见下方"去哪找 edge"。

## 去哪找 edge(模型调参救不了)

基础模型打不过 Pinnacle 主流盘,这是行业常识。真 edge 只可能来自:

1. **更软的市场**:低级别联赛、女足、杯赛、冷门联赛——Pinnacle 在这些地方报价没那么聪明。
   用 `download_data.py --leagues E1 E2 SC0 ...` 换这些联赛复跑,看 CLV 会不会翻正。
2. **市场没有的信息**:首发/伤停/轮换(赛前才公布)、天气、赛程密度、动机(保级/欧战)。
   把这些做成特征喂进模型,才有机会比市场早看到价值。
3. **更早的价格**:盯开盘到收盘的线移动,在 Pinnacle 还没修正前进场。
4. **只打亚盘大小球**:水位最低,edge 被抽水吃得最少(下载器已留亚盘列,可加进引擎)。

## 复跑/换样本(模式 A)

1. 在**你自己的电脑**上(能联网)运行:
   ```
   python download_data.py --leagues E0 D1 I1 SP1 F1 --seasons 1920 2021 2122 2223 2324 2425
   ```
   生成 `data/matches_clean.csv`(约 1 万+ 场)。
2. 把整个 `data/` 目录交回给 Cowork(或本机装好 numpy/scipy 直接跑):
   ```
   python backtest_value.py
   ```
   样本足够时自动切到**模式 A**:walk-forward 独立 Dixon-Coles 模型 vs 开盘 Pinnacle。
3. 看输出里的 **平均 CLV 和它的 t 值**:
   - 平均 CLV 持续 > 0 且 t 显著(几百上千注后)→ 你**真的**比收盘市场更早看到价值,这是 edge 最硬的证据。
   - CLV ≈ 0 或为负 → 模型只是在复述市场,没 edge,别下注。

## 如果你确实想用它做参考下注(诚实用法)

模型≈"市场共识的略糙版",所以只当**二次意见 + 分歧探测器**,绝不当选号器。

**1. 看某场的参考概率(向市场收缩)**
```
python predict.py --home "Arsenal" --away "Chelsea" --league E0 \
    --h 2.10 --d 3.50 --a 3.40 --over 1.90 --under 1.95
```
输出"模型 / 市场 / 混合"三栏。默认 α=0.3(以市场为主、模型微调)。
只关注**分歧≥6%**的盘口——那是值得你人工再看一眼的场次(前提是你有市场没有的信息)。
队名要和数据完全一致(如 `Man United`、`Nott'm Forest`)。

**2. 记录并监督你自己的下注(最重要的习惯)**
```
# 赛前下注时记两个价
python clv_tracker.py add --match "Arsenal vs Chelsea" --pick H --entry 2.10 --close 2.00
# 赛后补结果
python clv_tracker.py result --id 1 --outcome win
# 随时看记分卡
python clv_tracker.py report
```
盯住**平均 CLV**:几百注后仍显著为正 = 你真在加价值;否则该停。

**3. 用 Pinnacle 多盘口反推比分 + 量软盘错价(最有前途的路子)**
```
python score_from_market.py --h 1.95 --d 3.60 --a 4.00 \
    --over 1.90 --under 1.95 --ahline -0.25 --ahhome 1.95 --ahaway 1.95 \
    --soft "2-1:9.0" "1-1:6.5" "1-0:8.5" --edge 0.05
```
逻辑:Pinnacle 主盘口反推出**公允比分概率**(它的镜子,打不过它);
拿这把尺子去量**软盘**(bet365 等)的比分赔率——软盘哪个比分给得比公允长 ≥5%,
那里才可能有真 edge(软盘在比分这种冷门盘上常报错价)。
比分赔率 football-data 没有,需你从软盘手工填进 `--soft`。

**4. 信哪个盘口**:大小球/亚盘 > 1X2 ≫ 精确比分(自己猜的精确比分别信;反推的公允比分只用来量软盘)。
**5. 下注纪律**:固定小注或≤1/4 凯利,单注≤本金 1-2%,设止损,只投输得起的钱。

> 风险提示:我不是财务顾问。博彩有真实资金风险;软盘会限制盈利账户;理论 edge≠实盘 edge。
> 本模型经 1.8 万注回测对 Pinnacle 为**负 CLV**,因此它是分析参考,不构成"能赚钱"的依据。

## 防自欺铁律(已内建到引擎,务必遵守)

- **时间切分 + walk-forward**:引擎只用开赛前数据拟合,杜绝偷看未来。✔ 已实现
- **CLV 当终极裁判**,不是 ROI;ROI 噪声大、CLV 更早可信。✔ 已实现 t 统计
- **样本量**:几十注=噪声,**几百到上千注**才开始能信。
- **换联赛/换赛季复测**:`matches_clean.csv` 含 League 字段,可分联赛跑,一换就没=过拟合。
- **多重比较**:别试 50 套参数挑最好那套;每多试一套,"最好"越可能是运气。
- **表达 edge 优先亚盘大小球**(水位最低)。下载器已保留亚盘列(`AHh/PAHH/PAHA/...`),
  下一步可在引擎里加亚盘盘口的 value 检验。
